商标局入口：https://sbj.cnipa.gov.cn/sbj/index.html 。商标局对查询登录要求的官方答复：https://www.cnipa.gov.cn/jact/front/mailpubdetail.do?sysid=13&transactId=502906 。建议在第 9 类（计算机软件、相机相关）及第 42 类（软件服务）等实际经营覆盖的商品/服务上，对「取景」「取景相机」、读音与近似标识进行相同及近似检索，并对申请日、权利状态、商品项目逐项判断。未登录取得记录前**不能宣传“商标已通过检索”“零冲突”**。

## 删除边界与 Android 签名

历史重建只能使当前主分支不再引用原有提交；GitHub 服务端临时对象、缓存、Pull Request 引用、用户过去克隆和已外发材料可能仍保留旧字节。需要平台协助进一步移除不可见 Git 对象时应通过 GitHub Support 的敏感数据删除程序处理，不能声称删除已传播副本。

Android 正式签名的**公开证书主体和摘要可以从 APK 提取**，即使源码和构建日志不包含这些数据也无法隐藏；要改变签名身份必须由密钥持有人重新选择证书，并评估旧安装包是否还能直接更新。不要擅自删除或轮换仓库外的真实签名密钥，否则会破坏后续升级能力。
