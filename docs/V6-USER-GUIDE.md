# 取景相机 V6 / 0.6.0 使用说明

## 安装与离线

使用本次的 `qujing-camera-0.6.0-release.apk`。包名和签名沿用 0.5.0，可作为同签名升级包安装。APK 自带页面、模型、姿势与示例，不需要首次联网下载资源，仅申请相机权限。

应用没有联网权限；这不等于替整台手机关闭网络。要让整台设备离线，请自行关闭网络或启用飞行模式。保存和导入时选择设备本地文件位置。

## 一次拍摄的操作

1. 打开相机并授权。顶部可切换画幅、开启 3 秒定时，设置放在右上角。
2. 底部选“引导”，先选景别，再选构图和动作。远景、大远景指景别，人物占画面较小；中景、近景按身体裁切显示参考。
3. 点“站位”后直接轻点或拖动画面摆火柴人，点“完成摆放”锁定。完整人物摆脚点，中近景摆脸部中心。
4. 取景底部点常用倍率，或点当前倍率展开连续滑条；也可双指缩放。画面会说明使用的是设备变焦还是数字裁剪。倍率和画幅改变后，重新确认参考位置。
5. 点顶部光线提示，查看亮度、高光、暗部和拍摄建议。只有设备确实提供曝光补偿时才能应用，再用滑条微调；不支持时保留说明与参考。
6. 底部选“风格”，选择原色、清透、柔暖、胶片、黑白，调节按钮可改明暗、对比、饱和与暖调。这些效果会写入照片；光线推荐不会自动覆盖你的选择。
7. 按快门，检查成片后点“保存照片”，在系统文件选择器中确认位置。取消保存后，照片仍留在预览中，可重试；关闭应用前请主动保存需要的照片。

## 背景站位怎样用

点当前引导提示，在“画面协调检查”里进入“比较背景站位”。先由你确认并圈出现场实际可站人的地面区域，再生成最多三个候选，选择并应用。建议先让人物移开，取得无遮挡背景。应用后保持机位，让人物靠近火柴人；手机明显移动后重新规划。

计算会考虑当前动作宽度、头手脚边界、景别占比、构图目标、当前裁剪与可见区域的明暗/边缘。张开双臂和侧身站立所需空间不同。可信人物框明显遮住目标头肩区域时，会提示无法判断，不把人物衣服当背景。

系统目前不识别道路、草地、天空、悬崖等场景类别，不测距离或深度，也不判断站立安全。所有候选都需要你现场确认。“位置匹配”只表示几何关系，不能等同于照片好看或姿势完成。

## 当前技术与限制

人脸位置使用 BlazeFace，兼容 TinyFaceDetector；人体位置使用 COCO-SSD Lite MobileNet V2，只取 person 类。人体框底边中点近似脚点，14 套关节火柴人是手工动作模板，当前不检测真人骨架，也不识别人是谁。

光线建议来自相机处理后的像素，不是光照度计；ISO、快门和白平衡提示只作人工参考。五种风格是本地画面处理，不能恢复已过曝细节，也不代替夜景、HDR 或降噪。

当前是离线 Android APK，界面由系统 WebView 运行，原生层负责权限和文件保存。操作布局按手机相机组织，但没有小米/徕卡专有算法和物理镜头切换能力。倍率与 EV 以实际设备提供的能力为准；不支持设备倍率时使用明确标注的数字裁剪。

本次完成了 281 项模块测试、三种尺寸的界面操作和实际 JPEG 导出。真机镜头、EV、流畅度、首启离线和发热仍需在你的目标手机上验收。
